# 📱 PhonePe Payment Analytics Dashboard

An interactive Power BI dashboard designed to analyze digital payment transactions, user behavior, and service performance. The dashboard provides real-time business insights through KPIs, dynamic visualizations, and interactive filters.

---

## 📌 Project Overview

This dashboard helps stakeholders monitor payment performance, transaction trends, customer engagement, and service-wise transaction value. It enables data-driven decision-making by presenting key business metrics in a clear and interactive format.

---

## 🎯 Business Objective

- Monitor overall payment performance
- Track transaction growth over time
- Analyze payment success rates
- Identify top-performing services
- Understand customer demographics
- Compare weekday vs weekend usage
- Discover high-value customers

## 💡 Key Insights

- Processed over **300K transactions** worth **₹3.47 Billion**.
- Achieved a **96% payment success rate**.
- Reached **108K unique users**.
- Weekday transactions accounted for **71.6%** of total activity.
- Money Transfer generated the highest transaction value.
- Gen X and Millennials contributed nearly **75%** of users.
- Transaction volume remained stable throughout the year.
- Top 5 users contributed significantly to transaction value.
- Month-over-Month growth remained around **9%**.
- Interactive filters allow detailed performance analysis.
